# 세특 한 줄 도우미

수업 중 지켜본 학생의 모습을 번호 하나, 버튼 하나로 기록하면 세특 초안 문장으로 엮어 주는 웹앱입니다. 학기말에 몰려오는 글쓰기 부담을 덜고, 학생 한 명 한 명의 모습을 떠올리며 다듬는 시간을 확보하는 것이 목표입니다.

설치 없이 `setuk_writer.html` 파일 하나를 크롬으로 열면 바로 사용할 수 있습니다.

## 주요 기능

- **학년·반·번호 선택**: 인원수만 설정하면 번호판이 만들어지고, 여러 학생을 한꺼번에 선택해 같은 관찰행동을 적용할 수 있습니다.
- **관찰행동 × 상·중·하**: 관찰행동마다 수준별 표현이 연결되어 있어 어색한 조합을 줄입니다.
- **자동 점검**: 바이트, 반복 표현, 주의 표현, 간단한 맞춤법, 같은 반 문장 유사도를 확인합니다.
- **종목 확장**: 배드민턴과 농구가 기본으로 들어 있고, 종목 이름만 입력해 새 종목을 추가할 수 있습니다.
- **내보내기**: 복사, CSV 내려받기, 백업과 복원을 지원합니다.
- **개인정보 보호**: 데이터는 브라우저 안에만 저장되며 이름 입력은 선택 사항입니다.

## 빠른 시작

1. `setuk_writer.html`을 내려받아 크롬으로 엽니다.
2. **학급** 탭에서 학급(학년, 반, 인원수)을 추가합니다.
3. **작성** 탭에서 종목과 번호를 고르고, 관찰행동의 수준(상·중·하)을 누릅니다.
4. **선택한 학생 모두에 적용**을 누른 뒤 **선택한 학생 문장 만들기**를 누릅니다.
5. 점검 결과를 보고 문장을 다듬은 다음 **복사하기**로 가져다 씁니다.

## 화면 구성

| 탭 | 하는 일 |
|---|---|
| 작성 | 종목·학년·반·번호 선택, 관찰행동 체크, 문장 생성과 수정 |
| 학급 | 학급 추가, 인원수 변경, 이름 입력(선택), 저장 데이터 삭제 |
| 문장 DB | 종목과 관찰행동 편집, 연결어·마무리 문장·문장 틀, 글자수 제한과 점검 설정 |
| 결과 모아보기 | 만든 문장 모아보기, 비슷한 문장 찾기, CSV·백업 |

## 새 종목 추가하기

1. **문장 DB** 탭에서 새 종목 이름을 입력하고 **종목 추가하기**를 누릅니다.
2. 기본으로 만들어진 관찰행동의 이름과 활동 장면을 종목에 맞게 고칩니다.
3. 상·중·하 표현을 한 줄에 하나씩 적습니다. 표현은 "~함", "~보임"처럼 끝나게 적어 주세요.
4. 필요하면 **관찰행동 추가**로 영역을 늘립니다.

참여 태도, 협력·배려, 규칙·안전, 성장·도전은 공통 태도로 모든 종목에서 함께 쓰입니다.

## 알아 둘 점

- 생성 문장은 **초안**입니다. 실제 관찰하지 않은 내용이 포함되지 않았는지 교사가 확인해 주세요.
- 바이트 기본값은 1,500(500자)입니다. 학교와 항목의 기재요령에 맞춰 설정에서 조정하세요.
- 맞춤법 점검은 간단한 방식이므로 최종 문장은 맞춤법 검사기로 한 번 더 확인하세요.
- 공용 컴퓨터에서는 사용 후 백업 파일을 받고 **학급 탭**의 저장 데이터 삭제 버튼으로 기록을 지워 주세요.
- 시연과 테스트에는 가상 학급 데이터를 사용하세요.
